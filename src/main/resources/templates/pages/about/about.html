О проекте

Демонстрационная информационная система для больницы.

Проект реализован в рамках курсовой работы по дисциплине «Технологии программирования» студентами РУТ группы УВП-212.

Серверная часть: Java 21, Spring Boot, JPA. Клиентская часть: HTML, CSS и JavaScript. Данные предметной области включают пользователей, врачей, пациентов, специальности, медосмотры, приёмы и записи в медицинской карте.
